# THUNDERBIRD.ESQ

> A browser-native reimagining of System 6, with IRIX visual brutality.

THUNDERBIRD.ESQ is a speculative operating environment rendered in pure HTML/CSS/JS—fusing the clarity of Apple System 6 with the glamor of SGI IRIX. It's fully client-side, privacy-respecting, and aesthetic-maximalist.

- No telemetry, no accounts, no cloud
- System 6 windowing + IRIX theming
- Built-in creative tools: BIG GIFS, CHIPTUNE COMPOSER, SPRITE SLICER
- Operates like an OS, lives inside the browser

## Live Principles

- **Keyboard-first** with mouse fallback
- **Modularity** through sandboxed apps
- **System.css** for style, nostalgia, and interface purity

## Run it Locally

```bash
npm install
npm run dev
```
