# Design Rules – THUNDERBIRD.ESQ

## Visuals
- 1-bit fidelity UI
- 8px minimum padding/margin grid
- B/W or dithered backgrounds

## Motion
- Instant snap actions only (<50ms)
- No fade-ins unless irix-theme.css is enabled

## Audio
- Confirmation, cancel, and error sounds required
- Sound design must resemble early Macintosh UX

## Accessibility
- Keyboard must be sufficient for full interaction
- Optional toggle for high contrast themes
