# Product Requirements Document (PRD) – THUNDERBIRD.ESQ

## Purpose
A complete emulation of a System 6-styled operating environment inside the browser, combining pixel-perfect UX with full local-first functionality.

## Users
- Creative professionals
- Lurkers and anonymous users
- Privacy-focused developers
- Retro-computing enthusiasts

## Scope
- Browser-native desktop UX
- Local asset management
- Optional BBS and peer-to-peer file transfer

## Out of Scope
- No external authentication
- No cloud storage or SaaS hooks
- No modern UI frameworks

## Success Metrics
- Pixel-accurate System 6 visual fidelity
- Offline usability at 100%
- Local file export/import at 100%
- 1MB max memory footprint for system UI baseline
