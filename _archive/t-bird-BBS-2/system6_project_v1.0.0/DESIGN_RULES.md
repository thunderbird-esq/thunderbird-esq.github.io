# DESIGN RULES - Thunderbird BBS System 6 Facsimile

## Visual Standards
- **Primary Color:** #FFFFFF (White)
- **Secondary Color:** #000000 (Black)
- **Tertiary Color:** #A5A5A5 (Light Gray)
- **Selection Color:** #0000CC (System 6 Blue)

## Typography
- **Primary Font:** ChicagoFLF (system headings and windows)
- **Secondary Font:** Geneva (body text, menus)
- **Monospace Font:** Monaco (terminal, logs)

## Layout
- Desktop uses a grid-patterned background.
- Windows have black borders and gray title bars.
- Menus drop down, classic Apple Human Interface pattern.
- Draggable windows via title bars only.

## Interaction Rules
- Bootscreen launches on page load.
- Desktop icons open application windows on click.
- Modem sequence required before entering BBS interface.
- BBS terminal accepts typed commands (HELP, LOGIN, LIST, QUIT).

## Animations
- CRT-style flicker applied to terminal windows.
- Blinking question mark on the boot screen.
