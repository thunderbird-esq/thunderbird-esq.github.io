# THUNDERBIRD.ESQ – DEVLOG.md

This document tracks all meaningful changes, contributions, and iterations to the system and its components.  
**Every contributor must log their changes here immediately after merge.**

---

## 🗂️ Log Format

Each entry must include:

- **Date** (YYYY-MM-DD)
- **Contributor** (GitHub handle or name)
- **Changed Files/Modules**
- **Summary**
- **Rationale**
- **Outcome**
- **Tested on** (browsers/devices)

---

## 📘 Example Entry

### 2025-04-25 – @coredev

- **Changed**: `/apps/big-gifs/main.js`, `/core/utils/image.js`
- **Summary**: Implemented frame-by-frame preview rendering for BIG GIFS
- **Rationale**: Improves user feedback and allows precise frame editing
- **Outcome**: Feature works on Chrome and Firefox; tested with large GIFs
- **Tested on**: Firefox 124, Chrome 123, macOS, Windows
